# Team API Contracts (JSON)

An **API Contract** is simply an agreement between team members on exactly what the data will look like when passed from one person's system to another's. 

By agreeing on these exact structures right now (Day 1), you don't have to wait for each other. For example, Member 4 (Frontend) doesn't need to wait for Member 3 (AI) to finish the AI logic. Member 4 can just hardcode the `Intervention Alert` JSON below into their frontend app and start designing the UI immediately. When Member 3 is done, they just swap the hardcoded JSON with the live API call.

Here are the 3 core contracts your team needs to agree on:

---

### Contract 1: M1 (Ingestion) ➔ M2 (State Engine)
**What it is:** The standard format for any piece of financial data extracted from SMS, receipts, or bank APIs.
**Format:** `Normalized Financial Event`

```json
{
  "event_id": "evt_987654321",
  "user_id": "usr_123",
  "timestamp": "2026-08-28T10:00:00Z",
  "source": "sms", // Can be "receipt", "bank_api", "user_input"
  "type": "expense", // Can be "income", "expense", "bill_due"
  "amount": 45.50,
  "currency": "USD",
  "vendor": "Uber Eats",
  "confidence_score": 0.95, // Rule 1: Flag if OCR/parsing is uncertain
  "is_recurring": false
}
```

---

### Contract 2: M2 (State Engine) ➔ M3 (AI Brain) & M4 (Frontend)
**What it is:** The complete, current financial picture of the user, combining their current balance with M2's predictions for the future.
**Format:** `Financial State Snapshot`

```json
{
  "user_id": "usr_123",
  "last_updated": "2026-08-28T10:05:00Z",
  "current_balances": {
    "checking": 1250.00,
    "savings": 5000.00
  },
  "projected_income_30_days": {
    "estimated_amount": 3200.00,
    "variance": 400.00 // Rule 2: Accounting for income variability
  },
  "upcoming_obligations": [
    {
      "name": "Apartment Rent",
      "amount": 1100.00,
      "due_date": "2026-09-01T00:00:00Z",
      "category": "fixed_essential" // Rule 3: Fixed vs Discretionary
    }
  ],
  "active_goals": [
    {
      "name": "Emergency Fund",
      "target_amount": 10000.00,
      "current_amount": 5000.00,
      "priority": "high"
    }
  ],
  "safe_to_spend": 150.00 // Calculated by M2 based on projections
}
```

---

### Contract 3: M3 (AI Brain) ➔ M4 (Frontend)
**What it is:** The proactive alerts and advice generated by the LLM reasoning engine, formatted for the UI to display to the user.
**Format:** `Contextual Intervention`

```json
{
  "intervention_id": "int_456",
  "user_id": "usr_123",
  "timestamp": "2026-08-28T10:10:00Z",
  "severity": "high", // "info", "medium", "high"
  "title": "Upcoming Cash Flow Shortfall",
  "summary": "You may be short on cash for your rent payment next week.",
  "explanation": "Your rent of $1,100 is due on Sept 1st. Based on your variable gig income trends, we project you will only earn $800 before then. Your current checking balance is $150.", // Rule 5: Explainability
  "suggested_actions": [
    {
      "action_type": "transfer",
      "description": "Transfer $150 from your Emergency Fund to Checking to cover the gap.",
      "requires_user_approval": true
    },
    {
      "action_type": "budget_cut",
      "description": "Pause discretionary spending (dining out) for the next 4 days."
    }
  ]
}
```
